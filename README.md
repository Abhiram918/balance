# Balance

### Take control of your screen time.

Understand your computer habits. See where your time goes. Make room for what matters.

Balance is a Windows digital wellbeing application built with Flutter. It helps you understand how you spend your time across applications through usage tracking and activity insights.

## Features

| Feature | Description |
|---|---|
| **Application Usage** | Track the applications you use and the time you spend in them. |
| **Activity Insights** | Explore your usage patterns and understand where your time goes. |
| **App Limits** | Access tools designed to help manage time spent in selected applications. |
| **Focus Tools** | Use focus-oriented tools to support more intentional work sessions. |
| **System Tray** | Keep Balance accessible while you use your computer. |

## Installation

1. Download **Balance** using the button above.
2. Run `BalanceSetup.exe`.
3. Follow the installation instructions.
4. Launch Balance from the Windows Start menu or desktop shortcut.

> **Note:** Some features, including app limits and focus functionality, have limitations in this initial release.

## Built with

- [Flutter](https://flutter.dev/)
- [Dart](https://dart.dev/)
- SQLite for local data storage
