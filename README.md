# Balance

### Take control of your screen time.

Balance is a Windows digital wellbeing application built with Flutter. It helps you understand how you spend your time on your computer through application usage tracking, activity insights, and tools designed to encourage more intentional computer use.

## Features

- **Application Usage Tracking** — Monitor which applications you use and how much time you spend using them.
- **Activity Insights** — Explore usage information to better understand your computer habits.
- **App Limits** — Explore tools for setting application usage limits.
- **Focus Tools** — Access tools designed to support more intentional work sessions.
- **System Tray Integration** — Keep Balance accessible from the Windows system tray.

> **Note:** Some features, including app limits and focus functionality, have limitations in this initial release and may not enforce all intended behaviors.

## Installation

### Windows

1. Click **Download for Windows** above, or download the installer from the [v1.0.0 release page](https://github.com/Abhiram918/balance/releases/tag/v1.0.0).
2. Open `BalanceSetup.exe` after the download finishes.
3. Follow the installer instructions.
4. Launch **Balance** from the Start menu or your desktop shortcut.

**Requirements:** A compatible 64-bit Windows system.
